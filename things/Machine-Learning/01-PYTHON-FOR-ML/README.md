## Why this comes before ML libraries
NumPy, Pandas and scikit-learn are Python libraries. If variables, functions, collections and exceptions are mysterious, library calls become magic phrases to copy. Learn the basic language first, then introduce specialised libraries.

## Required skills
- Store and inspect values.
- Use lists and dictionaries.
- Write a function with parameters and a return value.
- Loop over data and apply conditions.
- Import a module and read a CSV file.
- Read a traceback and fix simple errors.

## Common beginner questions
**Must I master advanced Python before ML?** No. Focus on the concepts used to express data transformations and model workflows.  
**Are Python lists the same as NumPy arrays?** No. Lists are general-purpose containers; NumPy arrays are designed for efficient numerical operations.  
**Why use functions?** They give a task a name, accept inputs and return results, making code easier to test and reuse.

## Connection to Module 02
A list can hold numeric values, but ML calculations often operate on whole arrays of numbers. Next, NumPy introduces shapes, vectorised operations, broadcasting and matrix calculations.
