# Algorithm 09.6 — Decision Trees

## 1. Intuition
A decision tree asks a sequence of feature questions. For example: “Is area under 70?” One branch follows the true answer and another the false answer; further questions divide the data. A leaf produces a predicted class or numeric value.

Trees learn split rules from training examples. A classifier may choose splits that reduce impurity (such as Gini impurity or entropy); a regressor often uses reduction in a squared-error criterion.

## 2. Classification impurity intuition
If a node contains only class A, it is pure. If it contains a mix of classes, its impurity is higher under common criteria. A split is useful when child nodes are more pure than the parent, weighted by child sample counts. Exact splitting rules depend on the estimator and settings.

## 3. Fit a small model
```python
from sklearn.datasets import load_iris
from sklearn.model_selection import train_test_split
from sklearn.tree import DecisionTreeClassifier, export_text
from sklearn.metrics import accuracy_score

iris = load_iris()
X_train, X_test, y_train, y_test = train_test_split(
    iris.data, iris.target, test_size=0.25, random_state=42, stratify=iris.target
)
model = DecisionTreeClassifier(max_depth=3, random_state=42)
model.fit(X_train, y_train)
predictions = model.predict(X_test)
print("Accuracy:", round(accuracy_score(y_test, predictions), 3))
print(export_text(model, feature_names=list(iris.feature_names)))
```

This script uses scikit-learn's built-in Iris dataset. Accuracy and printed thresholds are generated by the model fit; run the script to observe exact output for the installed version.

## 4. Hyperparameters
- max_depth limits the tree depth.
- min_samples_split requires a minimum number of records to split a node.
- min_samples_leaf requires a minimum number of samples in a leaf.
- criterion chooses the split quality measure supported by the estimator.

Depth restrictions can reduce overfitting. Unrestricted trees can fit highly detailed rules, including noise. Pruning and validation are common tools for controlling complexity.

## 5. Strengths and weaknesses
**Strengths:** handles nonlinear relationships and feature interactions; little scaling is needed for typical numeric splits; rules can be inspected.
**Weaknesses:** small data changes can create different trees; deep trees overfit; tree boundaries are axis-aligned in the common implementation and can be less smooth than some alternatives; importance estimates can be biased in some settings.
