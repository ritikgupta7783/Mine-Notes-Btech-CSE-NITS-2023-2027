# Algorithm 09.13 — Gradient Boosting Classification

## Intuition
Gradient boosting classification adds weak learners sequentially to improve a classification loss. Later learners respond to errors or loss gradients from the current ensemble. The resulting decision score can be mapped into class probabilities depending on the implementation/objective.

## Example
```python
from sklearn.datasets import load_breast_cancer
from sklearn.ensemble import HistGradientBoostingClassifier
from sklearn.metrics import f1_score
from sklearn.model_selection import train_test_split

data = load_breast_cancer()
X_train, X_test, y_train, y_test = train_test_split(
    data.data, data.target, test_size=0.25, random_state=42, stratify=data.target
)
model = HistGradientBoostingClassifier(
    max_iter=100, learning_rate=0.1, max_leaf_nodes=15, random_state=42
)
model.fit(X_train, y_train)
predictions = model.predict(X_test)
print("F1:", round(f1_score(y_test, predictions), 3))
```

The F1 score must be generated by running this example. The dataset is a public built-in teaching dataset; it does not make this model appropriate for clinical decisions.

## Key settings
- max_iter: number of boosting stages.
- learning_rate: contribution scale per stage.
- max_leaf_nodes/max_depth: tree complexity.
- l2_regularization and early-stopping controls where supported.
- Loss/objective: classification target and probability conventions.

A smaller learning rate often needs more iterations; deeper trees can fit more complex interactions but may overfit. Evaluate under the same protocol as baseline/alternatives.

## Questions
1. Why sequential? Each stage works to improve the existing ensemble's objective.
2. How is this different from random forest? Forests aggregate independently/randomly grown trees; boosting corrects current errors stage by stage.
3. Does F1 encode all business costs? No, thresholds and false-positive/false-negative costs may need explicit analysis.
4. Why validate hyperparameters? To select complexity without repeatedly adapting to final test results.
