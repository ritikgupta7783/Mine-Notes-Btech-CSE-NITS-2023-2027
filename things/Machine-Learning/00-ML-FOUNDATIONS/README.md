# Module 00 — Machine Learning Foundations

**Level:** Absolute beginner · **Time:** 2–3 study sessions  
**Prerequisite:** Basic comfort reading a simple program; Python will be taught in Module 01.

## What this module teaches
You will learn what AI and ML mean, how ordinary rule-based programming differs from learning from examples, what a dataset/features/target/model are, the main learning problem types, and what happens between raw records and a prediction.

## Key idea before starting
A machine-learning system does not automatically “understand” a problem as a human does. It uses data and an algorithm to fit a model according to an objective. Its predictions can be useful, wrong, biased, overconfident or invalid when the new data differs from the training data.

## After this module, you should be able to
- Distinguish AI, ML, Deep Learning and Data Science at an introductory level.
- Explain features vs target and sample vs dataset.
- Describe training vs inference.
- Distinguish regression, classification and clustering.
- Sketch a basic ML pipeline and identify at least two ways it can fail.

## Beginner questions
**Does ML always mean neural networks?** No. Linear regression, decision trees, KNN and Naive Bayes are also ML algorithms.  
**Does a model learn perfectly from more data?** Not necessarily. More data helps only when it is relevant, sufficiently representative and used appropriately.  
**Does an ML prediction prove why something happened?** No. Prediction and causal explanation are different tasks.
