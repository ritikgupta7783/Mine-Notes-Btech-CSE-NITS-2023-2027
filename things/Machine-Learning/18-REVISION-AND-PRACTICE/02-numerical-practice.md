# Revision Set 18.2 — Numerical Practice

Solve the calculations by hand and show the intermediate steps.

## 1. Mean and spread
For x=[2,4,6]:
- calculate mean;
- calculate population variance and population standard deviation;
- calculate sample variance.

## 2. Linear prediction
A model uses ŷ=3x+5. Calculate prediction for x=7. Explain whether the coefficient 3 is automatically causal.

## 3. Dot product
Calculate [2,−1,3] dot [4,5,2]. Describe its role in a linear model.

## 4. Gradient step
J(w)=(w−4)², derivative J'(w)=2(w−4). At w=1, η=0.2, calculate the gradient and next w.

## 5. Regression metrics
True y=[10,20,30]; prediction=[12,18,25]. Calculate absolute errors, MAE, squared errors, MSE and RMSE.

## 6. Classification metrics
TP=36, TN=54, FP=6, FN=24. Calculate:
- total observations and accuracy;
- precision;
- recall;
- specificity;
- F1 using unrounded precision/recall.

## 7. Conditional probability
Suppose P(A∩B)=0.18 and P(B)=0.30. Calculate P(A|B) and explain the denominator.

## 8. Distance
Calculate Euclidean and Manhattan distance between (2,3) and (5,7). Which is used by KNN depends on the metric choice; explain why scaling can change which point is nearest.
