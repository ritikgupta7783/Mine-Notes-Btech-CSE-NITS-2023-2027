## How to use the questions
- First pass: solve without notes.
- Second pass: explain why each wrong choice is wrong.
- Coding: run the example, alter one assumption and test again.
- After one week: redo only the questions you missed.
- Update [Progress Tracker](../PROGRESS-TRACKER.md) with the remaining doubts.

The practice set is not a certification of expertise. It is a diagnostic tool to reveal what needs more study.
