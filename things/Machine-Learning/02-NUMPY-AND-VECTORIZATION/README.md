## Why NumPy matters
Python lists are general containers. NumPy arrays are designed for numerical data and support fast element-wise operations, slicing, aggregation and linear algebra. Many Python ML APIs accept NumPy arrays or table-like data that is converted into arrays internally.

## Checkpoint skills
- Explain scalar, vector, matrix, shape and axis.
- Predict the shape of slicing and reshaping operations.
- Tell element-wise multiplication apart from matrix multiplication.
- Explain simple broadcasting and identify incompatible shapes.
- Compute a dot product manually and interpret a vectorised result.

## Connection to Module 03
NumPy is useful for numerical calculations. Pandas builds table-oriented tools on top of similar data structures, making it easier to inspect column names, missing values and real CSV datasets.
