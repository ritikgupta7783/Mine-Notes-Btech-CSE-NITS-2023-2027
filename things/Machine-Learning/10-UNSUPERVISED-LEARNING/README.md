# Module 10 — Unsupervised Learning

**Prerequisites:** feature matrices, distance, scaling, statistics and preprocessing.  
**Goal:** explore structure when the dataset has no supplied target labels.

## Lessons
1. [Clustering and K-means](01-clustering-and-kmeans.md)
2. [Hierarchical clustering and DBSCAN](02-hierarchical-clustering-dbscan.md)
3. [Principal Component Analysis (PCA)](03-pca-dimensionality-reduction.md)

## Key warning
An algorithm can always produce a grouping under its rule; that does not mean the groups represent natural or useful categories. Inspect stability, distributions, domain context and intended use. Clusters are hypotheses to interpret, not automatic truths.

## Checkpoint
- Explain unsupervised vs supervised learning.
- Trace K-means assignment and centroid update steps.
- Explain why K-means is sensitive to feature scale and initialisation.
- Describe how PCA creates lower-dimensional components.
- Use a clustering metric carefully and state its limitations.
