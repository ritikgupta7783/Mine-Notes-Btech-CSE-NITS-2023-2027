# Machine Learning Glossary

This glossary uses short definitions. Follow the linked module for the full explanation.

- **Algorithm:** a defined procedure used to solve a problem or learn from data.
- **Artificial Intelligence (AI):** a broad field focused on systems performing tasks associated with intelligent behaviour.
- **Bias (model):** systematic error from assumptions that are too restrictive; the word can also mean dataset or social bias, depending on context.
- **Classification:** predicting a discrete category, such as spam/not spam.
- **Clustering:** grouping samples based on similarities without provided class labels.
- **Correlation:** a measure of how variables vary together; it does not by itself establish causation.
- **Data leakage:** using information during training or model selection that would not legitimately be available at that stage or at prediction time.
- **Dataset:** a collection of observations and their recorded fields.
- **Feature:** an input variable used by a model.
- **Generalisation:** performance on relevant unseen data, not only on training examples.
- **Gradient:** direction and rate information about how a function changes with its inputs.
- **Gradient descent:** an optimisation procedure that updates parameters in a direction that aims to reduce an objective.
- **Hyperparameter:** a setting chosen outside the fitting process, such as tree depth or KNN neighbour count.
- **Inference:** using a fitted model to produce predictions for new inputs.
- **Label/target:** the outcome a supervised model is trained to predict.
- **Loss function:** a numerical measure of prediction error for an example or batch.
- **Model:** a learned or specified mapping from inputs to outputs.
- **Observation/sample:** one example/row in a dataset.
- **Overfitting:** fitting training-specific patterns/noise that do not transfer well to unseen data.
- **Parameter:** a value learned by the model during fitting, such as a regression coefficient.
- **Precision:** among predicted positives, the fraction that are true positives.
- **Recall:** among actual positives, the fraction detected as positive.
- **Regression:** predicting a numerical quantity.
- **Regularisation:** a technique that discourages overly complex models or parameter values to improve generalisation.
- **Standard deviation:** a measure of spread around a mean, in the same units as the data.
- **Supervised learning:** learning a mapping using examples with known target labels/values.
- **Test set:** held-out data used for a final evaluation after model decisions are made.
- **Training set:** data used to fit model parameters and training-stage preprocessing.
- **Underfitting:** a model is too limited to capture important patterns even in the training data.
- **Unsupervised learning:** finding structure in data without supplied target labels.
- **Validation set:** data used to compare choices during development; it should not be treated as a final untouched test set.
- **Variance:** in statistics, spread of values; in the bias-variance discussion, sensitivity of a fitted model to training-data changes. Context matters.
