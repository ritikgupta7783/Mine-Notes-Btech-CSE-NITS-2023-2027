# Module 07 — Core Machine Learning Fundamentals

**Prerequisites:** Modules 00–06. This module connects data, maths and statistics into a valid learning process.

## Lessons
1. [Targets, splits, baselines, loss and fitting](01-training-loss-and-splits.md)
2. [Overfitting, generalisation, regularisation and cross-validation](02-generalization-overfitting-validation.md)
3. [Data leakage and reproducibility](03-data-leakage-and-reproducibility.md)

## Learning outcomes
- Describe exactly what an algorithm learns during fit().
- Explain the role of a training, validation and test split.
- Recognise overfitting and underfitting using train/validation behaviour.
- Understand parameters vs hyperparameters.
- Design a baseline before tuning.
- Give examples of data leakage and explain why it invalidates evaluation.
