# Module 16 — Practical Machine Learning Projects

The projects below apply the course in increasing order. Start by writing down the target and prediction time; only then write code.

## Project index
1. [Student Performance Prediction](01-student-performance-prediction/README.md) — regression, baseline, MAE/RMSE.
2. [House Price Prediction](02-house-price-prediction/README.md) — multiple features, regularisation and residual thinking.
3. [Spam Message Classification](03-spam-message-classification/README.md) — text vectorisation, Naive Bayes, precision/recall.
4. [Customer Segmentation](04-customer-segmentation/README.md) — scaling, K-means, PCA and silhouette.
5. [Customer Churn Classification](05-customer-churn-classification/README.md) — class imbalance, confusion matrix and threshold awareness.

Each project has a self-contained Python script or clearly labelled runnable steps. The examples use small synthetic data or a dataset included with scikit-learn, so they do not require paid APIs or a custom file download.

## Before you call a project complete
- [ ] Explain the target and each feature.
- [ ] State when the prediction is made and which fields are known then.
- [ ] Run the script in your own environment.
- [ ] Compare a simple baseline.
- [ ] Use an appropriate held-out metric.
- [ ] Inspect errors and edge cases.
- [ ] Document limitations and ethical concerns.
- [ ] Make one improvement based on a hypothesis.
- [ ] Explain the project without reading the README.

These small teaching projects are not production systems. Synthetic or tiny data only demonstrates the workflow and cannot support real business/medical/financial decisions.
