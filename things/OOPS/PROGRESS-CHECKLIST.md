# C++ OOP Course Progress Checklist

Check each task only when you can do it without copying the lesson.

## Unit 0 — C++ basics
- [ ] Explain main, headers, cout, variables and types.
- [ ] Write an if/else statement and a loop.
- [ ] Write a function with parameters and a return value.
- [ ] Use a simple array, string and struct.
- [ ] Compile and run a one-file program.

## Unit 1 — Why OOP?
- [ ] Explain the limitations of scattered variables.
- [ ] Explain procedural programming and the role of functions.
- [ ] Define OOP, class, object, state and behaviour in plain English.

## Unit 2 — Classes and objects
- [ ] Write a minimal class with data and one member function.
- [ ] Create two objects and demonstrate separate values.
- [ ] Use the dot operator correctly.

## Unit 3 — Member functions
- [ ] Explain return type, parameters and void.
- [ ] Define a member function inside and outside a class.
- [ ] Explain the scope resolution operator (::).

## Unit 4 — Access specifiers
- [ ] Explain public, private and protected.
- [ ] Explain class vs struct defaults.
- [ ] Identify a compile-time private-access error.

## Unit 5 — Constructors
- [ ] Write default and parameterized constructors.
- [ ] Explain initializer lists.
- [ ] Explain initialization order and a basic use of this.

## Unit 6 — Encapsulation
- [ ] Protect a class invariant.
- [ ] Validate a deposit/withdraw operation.
- [ ] Explain why a blind setter can be dangerous.

## Unit 7 — Abstraction
- [ ] Explain an abstraction with a real-life example.
- [ ] Design a small public interface hiding internal steps.
- [ ] Compare encapsulation and abstraction.

## Unit 8 — Inheritance
- [ ] Write single and multilevel inheritance.
- [ ] Draw multiple and hierarchical inheritance diagrams.
- [ ] Explain access modes, overriding and constructor order.
- [ ] Explain diamond inheritance and virtual base classes.
- [ ] Decide whether composition or inheritance fits a relationship.

## Unit 9 — Polymorphism
- [ ] Compare overloading and overriding.
- [ ] Implement a pure virtual interface.
- [ ] Explain runtime dispatch and virtual destructors.
- [ ] Explain object slicing.

## Unit 10 — Additional concepts
- [ ] Explain this, static, const and friend.
- [ ] Compare association, aggregation and composition.
- [ ] Explain copying, RAII and smart pointers.
- [ ] Handle an exception.
- [ ] Write a simple template, use a namespace and split a class into header/source files.

## Unit 11 — Projects
- [ ] Complete Student Profile Manager.
- [ ] Complete Rectangle/Circle Calculator.
- [ ] Complete Bank Account Manager.
- [ ] Complete College Result Manager.
- [ ] Complete Library Manager.
- [ ] Complete Employee Payroll.
- [ ] Complete Shape Polymorphism.
- [ ] Complete Multi-class Payroll.

## Unit 12 — Revision and interviews
- [ ] Answer the core interview questions aloud.
- [ ] Predict all output-tracing examples before running them.
- [ ] Debug access, constructor and overriding errors.
- [ ] Solve one coding challenge in each difficulty level.
- [ ] Explain at least one project using definition → reason → example → caveat.
