## Study method
For each chapter: understand the definition, trace the example, compile and modify it, then answer the interview questions aloud. Compile examples using `g++ -std=c++17 file.cpp -o app`.

**Accuracy note:** OA questions in this repository are representative practice, not claims that a named company asked the exact question. Add a company name only when a reliable source/date is available.
