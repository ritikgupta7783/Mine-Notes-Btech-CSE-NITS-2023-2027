## How to study
Read the theory, trace each example, compile and modify the code, then answer the interview questions aloud. Compile with: g++ -std=c++17 file.cpp -o app.

OA questions are representative practice, not claims that a named company asked the exact question. Company-specific attributions should include a reliable source and date.
